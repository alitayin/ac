# AgoraCash

eCash (XEC) eToken marketplace monitoring and trading platform built on the Agora protocol.

## Features

- Real-time eToken price tracking and order book
- Decentralized token swapping with Cashtab Connect
- Market analytics and transaction history
- Token listing services

## Getting Started

```bash
git clone <your-repo-url>
cd agoracash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000)

## Build

```bash
pnpm test
pnpm build
```

Run tests and build locally before pushing to ensure no errors.

## Tech Stack

Next.js 14, TypeScript, Tailwind CSS, ecash-lib, ecash-agora, chronik-client
